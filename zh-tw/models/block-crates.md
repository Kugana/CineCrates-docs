# 方塊型箱子

沒有模型外掛也沒關係。一行就能把箱子變成一般方塊：

```yaml
block: CHEST
```

![帶全息文字的方塊型箱子](../../assets/block-crates.png)

方塊會在箱子生成時放到放置點的座標上，取消放置時移除。它上方那段浮空文字是箱子的
`hologram:` —— 方塊型箱子與模型箱子的處理方式完全相同。

其餘一切行為都一模一樣——全息文字、點擊處理、每一種動畫、獎勵、鑰匙、限制、預覽
介面。**CineCrates 沒有任何功能是綁在「必須擁有模型外掛」之上的。**

## 挑選方塊

任何方塊材質都可以。幾個效果不錯的：

| 材質 | 說明 |
| --- | --- |
| `CHEST` | 最直覺的選擇。會面向你放置時看的方向。 |
| `ENDER_CHEST` | 不需要材質包就讀得出「特別」的感覺。 |
| `BARREL` | 適合箱蓋會穿進牆壁的地方。 |
| `SHULKER_BOX` | 有十六種顏色，所以每個階級可以有自己的色。 |
| `DECORATED_POT` | 佔地小，適合放在櫃檯上的箱子。 |

## 點擊

方塊型箱子**兩個滑鼠鍵都直接收得到**，所以 `interactions:` 裡的每一種綁定都能用，
沒有額外條件——不像模型箱子的左鍵還要看模型有沒有 hitbox。

## 全息文字

```yaml
hologram:
  - '&6Starter Crate'
  - '&7Right-click to open'
```

方塊上方的浮空文字，一項一行。方塊型與模型箱子的運作方式相同。

## 混用方塊與模型箱子

一個伺服器可以兩種都跑。模型後端只影響有設 `model:` 的箱子；設了 `block:` 的箱子
完全不理會它。這讓方塊型箱子很適合當作模型還在製作時的過渡，也適合那些你不想為它
花一個模型的低階箱子。

{% hint style="info" %}
如果一個箱子同時設了 `model:` 與 `block:`，**方塊優先**——完全不會生成實體。
移除 `block:` 才會回到模型。
{% endhint %}
